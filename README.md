# GymIQ Macro Intelligence Web

A modern gym-focused nutrition web app with animated UI and advanced meal-macro tracking.

## Features
- Meal image upload preview and meal keyword analysis.
- Macro estimation for calories, protein, carbs, fats, fiber, and sugar.
- Goal modes for cut, maintain, and lean bulk.
- Animated compliance ring and progress bars.
- Smart coach insights based on your latest macro profile.
- Theme toggle and workout calorie-burn logging.
